Run a test

Pick a device, point nimo at an APK, and it boots Android in the cloud (redroid, falling back to the emulator), runs the full test, and reports back — live, right here.

1 · Connect

A GitHub token starts your test run — saved only in this browser, used for nothing else. It needs Actions → read & write on datum-router/nimo (fine-grained token).

Create a token → repository access: datum-router/nimo · permissions: Actions → read & write

2 · Device

redroid boots first; if the runner kernel lacks binder, the standard emulator takes over automatically. arm64 needs your own ARM runner (GitHub-hosted ARM runners lack the kernel module).

3 · What to test

Upload is optional — a link is enough. An uploaded file goes to a temporary file host for this test run only, then the test runner downloads it.
